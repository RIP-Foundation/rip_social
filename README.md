# Rip Social - The Digital Courthouse

Rip Social is an open-source social platform designed for rigorous, logical, and transparent debate.

## Mission
To create a "Global Town Square" where interactions are real, raw, and accountable.
- **No Blocking:** Users are forced to coexist.
- **No Echo Chambers:** Engagement with opposing views is mandatory.
- **Digital Evidence:** Threats and abuse are not hidden; they are flagged and preserved as public evidence of bad behavior.

## Technology Stack
We utilize a high-performance, low-latency stack designed for real-time text processing.

### Backend (API & Runtime)
- **Runtime:** Bun v1.3+ (High-performance JavaScript runtime)
- **Framework:** ElysiaJS v1.4+ (End-to-end type safety)
- **Database:** PostgreSQL 18 (AWS RDS)
- **ORM:** Drizzle ORM v0.45+ (SQL-like, high performance)

### Frontend (User Interface)
- **Framework:** Next.js 16 (App Router, Server Components)
- **Styling:** Tailwind CSS v4.0 + Shadcn/UI (Brutalist Theme)

### AI Authority
- **Model:** Llama 3.3 (Open Source via Groq)
- **Role - The Police:** Intercepts posts pre-submission to enforce civility and flag threats.
- **Role - The Judge:** Analyzes threads to identify logical fallacies and summarize valid points.

## Infrastructure & Costs
- **Cloud Provider:** AWS (EC2/Fargate for Backend, RDS for Database).
- **Sustainability:** Relying on community funding to maintain server operations.
