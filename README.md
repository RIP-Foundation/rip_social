# Rip Social - The Digital Courthouse

**Rip Social** is an open-source social platform designed for furious, logical, and transparent debate.

## 🌍 The Mission
To create a "Global Town Square" where interactions are real, raw, and accountable. 
- **No Blocking:** We force coexistence.
- **No Echo Chambers:** You engage with opposing views.
- **Digital Evidence:** Threats and abuse are not hidden; they are flagged and preserved as public evidence of bad behavior.

## 🤖 The Technology: "The Speed Stack"
We use the fastest tools available to ensure real-time debate.

### **Backend (The Muscle)**
- **Runtime:** [Bun](https://bun.sh) (v1.0+)
- **Framework:** [ElysiaJS](https://elysiajs.com) - Optimized for Bun.
- **Database:** PostgreSQL (AWS RDS).
- **ORM:** Drizzle ORM - For maximum SQL performance.

### **Frontend (The Face)**
- **Framework:** Next.js 14 (App Router).
- **Styling:** Tailwind CSS + Shadcn/UI (Brutalist Theme).

### **AI Authority**
- **Model:** Llama 3 (Open Source via Groq).
- **Role:** 
    - **The Police:** Intercepts posts *before* they are published to enforce civility (no ad hominem) and flag threats.
    - **The Judge:** Analyzes threads to identify logical fallacies and summarize valid points.

## ☁️ Infrastructure & Costs
- **Cloud:** AWS (EC2/Fargate for Backend, RDS for DB).
