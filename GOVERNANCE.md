# Governance Model

## Overview

The **RIP Social** project is an open source project that welcomes contributions from the community. This document outlines the governance model for the project.

## Roles and Responsibilities

### Maintainers

Maintainers have write access to the project repository and are responsible for:
*   Reviewing and merging pull requests
*   Managing issues and labeling
*   Defining the project roadmap
*   Enforcing the Code of Conduct
*   Releasing new versions

### Contributors

Contributors are community members who:
*   Submit pull requests
*   Report bugs and suggest features
*   Improve documentation
*   Participate in discussions

### Project Lead

Akshaya Parida (@akshayaparida) creates the strategic vision for the project and has final say on major architectural and product decisions.

## Decision Making Process

Decisions are made by consensus among the Maintainers. If consensus cannot be reached, the Project Lead has the tie-breaking vote.

## Roadmap Planning

The roadmap is planned publicly in the GitHub Projects board. Community input is highly valued and considered during planning sessions.
